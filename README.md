# Teaching_English

Repository lưu trữ quy tắc làm việc và tài liệu hỗ trợ giáo viên Tiếng Anh lớp 6 sử dụng **Global Success**, phạm vi **Unit 1–6**.

## Quy tắc bắt buộc

Đọc [TEACHING_RULES.md](TEACHING_RULES.md) trước mỗi nhiệm vụ. Nếu có yêu cầu mới của giáo viên về quy tắc, cập nhật file và commit/push khi quyền GitHub sẵn có.

**Hiện hành:** Rules v1.0.0 (2026-11-24).

## Quy trình

1. Đọc rules phiên bản mới nhất trên nhánh `main`.
2. Xác định nội dung Unit 1–6 và mức độ phù hợp lớp 6.
3. Soạn tài liệu hoặc phản hồi đúng định dạng được yêu cầu; soát lỗi trước khi gửi.
4. Nếu có thay đổi rules: cập nhật phiên bản trong `TEACHING_RULES.md`, commit, xác minh và báo lại commit SHA.

Không có tác vụ tự động chạy nền; mọi lần cập nhật GitHub cần được thực hiện trong phiên làm việc có kết nối và quyền ghi.
